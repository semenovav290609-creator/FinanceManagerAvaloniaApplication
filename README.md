# Finance Manager Application (Avalonia UI Edition) 💰

**Finance Manager** — это современное, легкое кроссплатформенное десктопное приложение для контроля личных финансов. Проект полностью переписан с устаревшей платформы Windows Forms на современный фреймворк **Avalonia UI**, что обеспечивает высокую производительность и гибкий UI.

---

## 🔥 Ключевые особенности и фичи

* 📊 **Мгновенный расчет баланса:** Автоматический пересчет общего баланса и суммы всех потраченных средств в реальном времени при каждой операции.
* 📝 **Карточки истории:** Каждая транзакция выводится в виде аккуратной вертикальной карточки с выделением названия (Bold) и стоимости.
* 🎨 **Цветовое кодирование:** Суммы расходов автоматически подсвечиваются ярким красным цветом (`#C0392B`) для лучшего визуального восприятия.
* 📁 **Настоящее JSON-сохранение:** Все данные сериализуются в файл `history.json` с использованием официальной библиотеки `System.Text.Json`.
* 🇷🇺 **Полная поддержка кириллицы:** Настроен встроенный Unicode-энкодер, благодаря чему данные в JSON-файле хранятся в читаемом для человека виде (без кодов `\u04`).
* 🧹 **Быстрая очистка:** Возможность в один клик полностью обнулить историю транзакций и сбросить счетчик трат.

---

## 🛠️ Технологический стек

* **Язык программирования:** C# (.NET 8.0 / .NET 9.0)
* **Графический фреймворк:** Avalonia UI (кроссплатформенный XAML)
* **Формат данных:** JSON (`System.Text.Json`)
* **Архитектурный подход:** Разделение логики калькуляции и UI через динамическое построение визуального дерева элементов.

---

## 🏗️ Архитектура и структура кода

Приложение построено на строгой типизации данных. Логика сохранения опирается на класс-модель транзакции:

```csharp
public class TransactionSaveModel
{
    public string Name { get; set; } = string.Empty;
    public string Category { get; set; } = string.Empty;
    public string Price { get; set; } = string.Empty;
}
```

Все файловые операции (запись, проверка существования, чтение и десериализация) защищены блоками `try-catch`, что предотвращает падение программы при случайном повреждении файла конфигурации.

## 🚀 Как запустить проект

### Из исходного кода:
1. Клонируйте репозиторий.
2. Откройте решение в **Visual Studio 2022** или **JetBrains Rider**.
3. Убедитесь, что у вас установлено расширение для работы с Avalonia UI.
4. Нажмите `F5` для сборки и запуска.

### Как готовое приложение (Сборка в один файл):
Проект поддерживает автономную публикацию (`Self-contained`). Чтобы собрать приложение в один независимый `.exe` файл, выполните в терминале команду:
```bash
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```
После этого готовый исполняемый файл появится в папке `bin/Release/.../publish/` и запустится на любом ПК даже без установленного .NET SDK.
